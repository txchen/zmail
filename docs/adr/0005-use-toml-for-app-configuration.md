# Use TOML for App configuration

Zmail uses a local TOML file for **App configuration** instead of JSON embedded in environment variables, because the operator needs to declare **App login** credentials, SQLite storage location, sync policy, and **Configured Mail accounts** in a readable, diffable shape that can include secrets without being committed. By default Zmail loads `./zmail.toml`; `ZMAIL_CONFIG_PATH` selects a different file, with no merging between files. `zmail.toml` is ignored by git, `zmail.toml.example` documents the schema, **App login** and `[storage] database_dir` are always required, `[sync] recent_message_window_days` defaults to 90, and zero **Mail accounts** must be represented explicitly with `mail_accounts = []`.
