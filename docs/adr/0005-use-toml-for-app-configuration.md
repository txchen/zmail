# Use TOML for App configuration

Zmail uses a local TOML file for **App configuration** instead of JSON embedded in environment variables, because the operator needs to declare **App login** credentials, **Configured Mail accounts**, and reader behavior such as `reader.read_dwell_seconds` in a readable shape that can include secrets without being committed. By default Zmail loads `./zmail.toml`; `ZMAIL_CONFIG_PATH` selects a different file, with no merging between files. `zmail.toml` is ignored by git, `zmail.toml.example` documents the schema, Read dwell time defaults to three seconds and accepts `0..60`, zero **Mail accounts** must be represented explicitly with `mail_accounts = []`, and obsolete `[storage]` or `[sync]` tables are rejected rather than ignored.
