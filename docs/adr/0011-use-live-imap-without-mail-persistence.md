# Use live IMAP without mail persistence

Zmail reads and searches Gmail through live IMAP requests and does not persist Messages, Mailboxes, message bodies, search results, or sync state to disk. Each Mail account has at most one ordinary short-lived IMAP session; commands within one account are serialized, while different Mail accounts remain independent and may operate in parallel. Automatic IMAP IDLE is disabled, and each session remains reusable for a ten-second Interaction lease after the last user-triggered operation before closing. No application-level keepalive command is sent during the lease, while attachment downloads use independent sessions that last only for their streams. The server does not cache mail responses; previously visited views, pagination, and Message bodies are cache-first only in the browser's current in-memory page session until Manual refresh, and disappear on reload, logout, or page close. The new configuration rejects the obsolete storage section, the container no longer requires a data volume, and existing SQLite files are neither opened nor deleted. This supersedes ADR-0002 and ADR-0010 and replaces the Local read model described in ADR-0001.
